# La Palabra · Consejo bíblico

App para celulares (PWA) que responde con versículos, historias bíblicas y la mirada de cada tradición.
Ilustraciones: grabados de Gustave Doré (1866), dominio público, vía Project Gutenberg #8710.

Variables de entorno en Netlify:
- `ANTHROPIC_API_KEY` (obligatoria para la IA)
- `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` (opcionales, voz natural del abuelo)
